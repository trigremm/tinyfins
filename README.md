# tinyfins 🐠

Живой аквариум для малышей в духе [tinyfingers.net](https://tinyfingers.net):
рыбки плавают сами по себе, а каждое нажатие клавиши или касание экрана
добавляет рыбок, корм, пузыри и звуки. Малыш может стучать по клавиатуре
сколько угодно — компьютер в безопасности.

Без сборки, без зависимостей, без аккаунтов и трекинга: чистый HTML + Canvas +
Web Audio (все звуки синтезируются, аудиофайлов нет). После загрузки страница
не делает ни одного сетевого запроса.

## Запуск

```bash
make run          # локальный сервер на http://localhost:8000
PORT=9000 make run
```

Открыть как `file://` не получится — ES-модули требуют http, поэтому `make run`
обязателен. Чтобы открыть с телефона или планшета, зайдите на
`http://<IP-компьютера>:8000` из той же сети.

## Деплой (docker + traefik)

```bash
make r     # build + stop + up: nginx-контейнер на 127.0.0.1:8140
make d     # deploy: git pull + пересборка
make l     # логи
```

**Продакшен** (сервер с hostwide [dc-traefik](https://github.com/trigremm/dc-traefik):
маршрутизация по docker-лейблам в сети `traefik-public`, TLS — Let's Encrypt):

```bash
git clone git@github.com:trigremm/tinyfins.git && cd tinyfins
cp docker-compose.override.yaml.sample docker-compose.override.yaml
make r
```

Плюс DNS-запись `tinyfins.asmo.su` → IP сервера (Cloudflare).

**Локально** порт `127.0.0.1:8140` уже проброшен. Маршрута `tinyfins.local`
в `dc-traefik` сейчас нет: его динамическая конфигурация лежит в
`dc-traefik/traefik/dynamic/*.yml` (file-provider), туда и добавлять правило
`tinyfins.local → host.docker.internal:8140`, если понадобится красивое имя.

## Управление

| Действие | Реакция |
|---|---|
| Тап / клик по воде | круги на воде, пузыри + иногда корм или новая рыбка |
| Тап рядом с рыбой | рыба шарахается в сторону |
| Любая буква | нота (пентатоника) + новая рыбка; у каждой буквы свой вид |
| Цифры | столб пузырей |
| Пробел / Enter | кормёжка сверху — рыбы сплываются |
| Стрелки | «течение» — все рыбы качаются в сторону |

## Панель родителя

- Удерживайте любой угол экрана 2 секунды одним пальцем (второй палец
  отменяет — защита от детских ладошек), или
- наберите слово `parent` на клавиатуре.

В панели: звук вкл/выкл, режим «меньше движения», полный экран, сброс
аквариума. Настройки сохраняются в localStorage.

## Ограничения защиты

Блокируются: контекстное меню, выделение текста, зум (pinch и двойной тап),
pull-to-refresh, прокрутка, Tab/Space/F-клавиши и прочие клавиши в игре.
**Не** блокируются (браузер не позволяет): `Esc` — выход из полного экрана,
`Ctrl+W`, системные клавиши. Для полной блокировки запускайте
`chromium --kiosk http://localhost:8000`, либо «Гид-доступ» (iPad) /
закрепление приложения (Android).

## Отладка

- `?debug=1` — FPS и счётчики сущностей в углу экрана.
- `?autostart=1` — пропустить заставку (удобно при разработке).

Все настройки поведения (капы, скорости, виды рыб) — в `js/config.js`.
